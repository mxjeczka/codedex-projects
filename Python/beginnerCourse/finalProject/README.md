This project is an animated GIF creator developed as part of a Python final project.

In this project, multiple images are combined into a short animated story using Python and the ImageIO library.

## 📖 Description

The GIF tells the story of a little mermaid searching for magic beneath the ocean.

Across 13 different scenes, she discovers a mysterious pearl, explores the deep sea, unlocks hidden magic, and finally transforms into a human beneath the moonlight ✨

The project combines storytelling, image processing, and animation into a small visual experience.

## 🎮 Features

* Creating GIF animations with Python
* Combining multiple images into one animated sequence
* Automatic GIF generation using ImageIO
* Organized project structure with image and output folders
* Automatic opening of the finished GIF on Windows
* Simple file handling using `pathlib`

## 🖼️ Story Scenes

The animation includes:

* A lonely mermaid beneath the moonlight
* A magical shell with a glowing pearl
* An underwater journey into the deep sea
* A mysterious treasure chest full of magic
* A magical transformation scene
* The mermaid becoming human at the end of the story

## How to Use

1. Download or clone the project from GitHub.

2. Install the required library:

```bash
pip install imageio
```

3. Open the project and run:

```bash
python main.py
```

4. The GIF will automatically be created inside the `output` folder and opened on your computer.

>> You can also directly view the finished GIF by opening the `output` folder in this GitHub repository.
