## Contents

### 🪨📄✂️🦎🖖 Rock Paper Scissors Lizard Spock (Checkpoint Project)

A console-based game where you play Rock Paper Scissors Lizard Spock against the computer.

Features:

* Interactive user input using `input()`
* Random computer choices using `random`
* Extended game rules (Rock, Paper, Scissors, Lizard, Spock)
* Win, lose, and tie logic using conditionals
* Simple and interactive console gameplay
