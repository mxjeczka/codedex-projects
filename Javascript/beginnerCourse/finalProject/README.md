#  The One Ring – Pomodoro Timer

This project is a web-based Pomodoro timer developed as my final project for the JavaScript Beginner Course on Codédex.

Instead of creating a simple timer, I wanted to build something with a little more atmosphere. I decided to combine the Pomodoro technique with a fantasy-inspired design based on **The Lord of the Rings**.

The main timer is designed as a glowing One Ring, with a moving fantasy background and optional background music.

##  Description

The One Ring Pomodoro is a small focus timer that can be used for studying, coding, or working.

The timer is displayed inside a custom One Ring design. Behind it, a fantasy waterfall video plays continuously in a loop to create a calm and immersive atmosphere.

You can set the timer, start and stop it, and reset it whenever you want. There is also an optional background music button, with the music playing in a continuous loop.

I wanted to make something that feels less like a normal productivity tool and more like a small fantasy world you can work in. ✨

##  Features

* Pomodoro-style countdown timer
* Custom One Ring timer design
* Start, stop, and reset controls
* Adjustable timer duration
* Looping fantasy background video
* Optional looping background music
* Custom TrajanusBricks font
* Fantasy-inspired visual design
* Responsive web layout

##  How It Works

First, choose how many minutes you want the timer to run.

Press **Start** to begin the countdown.

You can use **Stop** to pause the timer and **Reset** to return to the original time.

The background video continues playing in a loop while you work.

You can also turn the background music on or off using the music button in the top right corner.
